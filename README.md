# Karta prototypes

Static builds of Karta prototypes, served via GitHub Pages for viewing on a phone.

| Folder | Link | Source |
|---|---|---|
| `card-flow/` | https://em111n.github.io/prototypes/card-flow/#/prototypes | Build copied from bhz-kart/card-flow (`src/prototypes/team/CardFlow1.tsx` / `CardFlow2.tsx` in bhz-kart/karta-design-system, `vite build --mode prototypes --base ./`) |

To update a prototype, replace its folder with a fresh build and push to `main`.
